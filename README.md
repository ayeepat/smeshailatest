# СМЭШ AI — последняя версия

Здесь лежит самая свежая сборка расширения СМЭШ AI для Chrome, пока она проходит проверку в Chrome Web Store.

**Текущая версия: 1.0.3.16**

[⬇️ Скачать smesh-ai-chrome-v1.0.3.16.zip](https://github.com/ayeepat/smeshailatest/releases/latest/download/smesh-ai-chrome-v1.0.3.16.zip)

## Что нового в 1.0.3.16

Исправлена ошибка «signal is aborted without reason» в каталоге ГДЗ: каталог, готовые ответы и обложки теперь загружаются небольшими частями, которые провайдер не блокирует.

Исправлена ошибка, из-за которой у части пользователей в России тесты останавливались с красной ошибкой при загрузке задания. Теперь каждый запрос к серверу идёт по отдельному соединению, и провайдер не может его «заморозить».

## Установка (первый раз)

1. Скачайте zip-файл по ссылке выше.
2. Распакуйте его в папку, которую вы **не будете удалять** — например, `Документы/СМЭШ AI`. Chrome берёт расширение прямо из этой папки.
3. Откройте в Chrome адрес `chrome://extensions`.
4. Включите **«Режим разработчика»** (переключатель справа вверху).
5. Нажмите **«Загрузить распакованное расширение»** и выберите распакованную папку. Внутри неё должен лежать файл `manifest.json`.
6. Нажмите на значок пазла справа от адресной строки и закрепите СМЭШ AI.
7. Откройте расширение и введите свой ключ доступа (`SMESH-…`).

## Обновление (если уже ставили отсюда)

Так ключ и настройки сохранятся:

1. Скачайте новый zip.
2. Распакуйте его **в ту же папку**, заменив старые файлы.
3. Откройте `chrome://extensions` и нажмите круглую стрелку «Обновить» на карточке СМЭШ AI.

Не удаляйте старое расширение и не ставьте новое из другой папки: Chrome посчитает его новым устройством, и ключ придётся активировать заново.

## Если стоит версия из Chrome Web Store

Выключите её переключателем на странице `chrome://extensions`, чтобы две копии не мешали друг другу. Когда новая версия появится в магазине, можно будет вернуться к ней.

## Что-то не работает?

Если появилась ошибка, нажмите «Сообщить об ошибке» в расширении и пришлите нам номер отчёта (ID).
